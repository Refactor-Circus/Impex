# @refactor-circus/impex-client

A typed fetch client for the Impex JSON API. `src/schema.d.ts` is generated by
[openapi-typescript](https://openapi-ts.dev/) from the package's committed
`openapi.json`, and `createImpexClient()` wraps
[openapi-fetch](https://openapi-ts.dev/openapi-fetch/)'s `createClient<paths>`.

The package ships TypeScript source only: there is no build step and no
`dist`. Its `exports` point at `src/index.ts`, so the consumer's bundler
(Atrium v2's Nuxt layer, for example) compiles it.

## Usage

```ts
import { createImpexClient } from '@refactor-circus/impex-client';

const impex = createImpexClient({
  // The host's API base URL, `impex.routes.prefix` included.
  baseUrl: 'https://app.test/impex',
  headers: { Authorization: `Bearer ${token}` },
});

const { data: stats } = await impex.GET('/stats');

const { data: runs, error } = await impex.GET('/search', {
  params: { query: { q: 'import', limit: 10 } },
});

const { data: run } = await impex.GET('/runs/{run}', {
  params: { path: { run: runId } },
});
```

`createImpexClient(options)` takes `baseUrl` plus any other openapi-fetch
`ClientOptions` (`headers`, `fetch`, `credentials`, ...) and returns a
`Client<paths>`. Paths, parameters, request bodies and responses are typed
from the OpenAPI document. The `paths`, `components` and `operations` types
are re-exported for code that needs a schema directly:

```ts
import type { components } from '@refactor-circus/impex-client';

type Run = components['schemas']['RunResource'];
```

## Installing from git

The client is not published to an npm registry. Consumers pin it as a git
dependency on a release tag. It lives in the `client/` folder of the Impex
repository, and npm cannot install a subfolder of a git repository, so use
pnpm (or Bun):

```json
{
  "dependencies": {
    "@refactor-circus/impex-client": "github:refactor-circus/impex#v2.0.0&path:/client"
  }
}
```

The tag must match the Impex version the host runs, so the client and the API
describe the same routes.

## Regenerating

Never edit `src/schema.d.ts` by hand. From the package root, run:

```bash
composer client:generate
```

It runs, in order:

1. `vendor/bin/testbench scramble:export --path=openapi.json`, which exports
   the OpenAPI document from the workbench;
2. `npm --prefix client ci`;
3. `npm --prefix client run generate`, which writes `src/schema.d.ts` from
   `../openapi.json`;
4. a write of `client/openapi.sha256`, the sha256 of the `openapi.json` the
   schema came from.

Commit `openapi.json` and everything that changed under `client/`. Then check
the client with:

```bash
npm --prefix client run typecheck
```

A stale copy is caught twice. In the Pest suite,
`tests/Feature/OpenApiTest.php` fails when a fresh export differs from
`openapi.json`, and `tests/Feature/ClientTest.php` fails when
`client/openapi.sha256` does not match it. In CI, the `client` job
regenerates everything, fails on any diff under `openapi.json` or `client/`,
and type-checks the client.

`openapi-typescript` and `typescript` are pinned to exact versions, and
`package-lock.json` is committed, so the generated schema is byte-stable.
